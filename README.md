# Portfolio

Case studies of my Roblox work. Each project has a folder with a full write-up; the code
lives in its own repository and is linked from there.

Start at **[MasterIndex.md](MasterIndex.md)**.

## Structure

```
01_Roblox/     Roblox projects, newest first
02_Web/        web work
03_Minecraft/  server administration
04_Archive/    retired experiments
```

## A note on the numbers

Case studies state measured results only. Where something has not been measured it says
`[TODO: measure]` instead of carrying a plausible-looking figure. Test counts, lint results
and commit counts come from the repositories themselves and can be reproduced by running the
commands named in each README.
